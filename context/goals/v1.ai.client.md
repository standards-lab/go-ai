## Decisions

- design: start found go-ai current (`mise run currency`), so no plan round opened; the brief
  approved at plan stands.
- design: the root package is `ai`, its errors prefixed `ai: `; `New(baseURL, httpClient,
  wireFormat, Options)` takes an options struct named `Options`, not `Config`, since a `Config` in
  the workspace is a go-core configuration block.
- design: `Options.Header` carries fixed headers (Anthropic's `x-api-key`, a gateway key); `New`
  refuses one naming Content-Type, Accept, or Authorization.
- design: `Options.StreamIdleTimeout` bounds each read of a started stream, owned by the library
  and off at zero (go-storage's `ReadIdleTimeout` is the precedent).
- design: the retry set is 408, 429, 502, 503, 504, and a connection failure before any reply; a
  retried POST may run twice; `APIError.RetryAfter` is a `time.Duration`.
- design: rejected an SSE encoder of the stream events; Cerebro maps the typed events itself.
- design: `Client.Models` is a GET through the same token, header, and retry path.
- design: Embed, Transcribe, and Models go to the OpenAI-compatible routes whatever the format,
  documented, not refused.
- design: `TranscriptionRequest.Open` takes a context, which the layers note's sketch doesn't.
- design: the base module stays stdlib-only, held by depguard and a check step asserting no
  `require` (the library task adds both); infer is nested at `tools/infer`; `go.work` comes with
  the infer task; the first tags are `v0.1.0` and `tools/infer/v0.1.0`, both pre-1.0.
- design: the library task owns `mise run upgrade`.
- design: STANDARDS.md keeps only the clauses an architecture page supports; the retry set, the
  `Options` name, and the missing encoder stay design decisions in `context/design.md`.
- design: of the spike's three client rules, rules 1 and 2 changed (widened) and rule 3 is kept.
- design: the design stays provisional until the library task builds it.
- plan: go-ai starts from a fresh `init`; the library task ports spike-ai-pipeline-client
  v0.4.0, whose tags sit under another module path and would collide with go-ai's.
- plan: init ships a check-only CI workflow, so the merge's check wait works from the first pull
  request; the release workflow comes with the library task.
- plan: `design` settles infer's nested module, its requirements, and its four subcommands (chat,
  embed, transcribe, models); flags and output wait for the infer task.
- plan: the retry proof against the live gateway (429, 503, Retry-After) is acceptance's, waiting
  on spike-model-gateway; the library task's release doesn't wait on the gateway.
- plan: rejected a vendor SDK (openai-go, anthropic-sdk-go) as the client: none covers all three
  wire formats, openai-go failed minimal-footprint (spike-harness-driver findings.md), and a
  provider enters a base module only through a sub-module (dependencies.md, "No provider in a
  base").
